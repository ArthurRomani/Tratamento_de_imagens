# Projeto: Processamento de Imagens com Python

## Descrição
Este projeto foi desenvolvido como parte da disciplina de Computação, com foco na manipulação e processamento de imagens em tons de cinza. Ele inclui funcionalidades para aplicar filtros como inversão de cores, desfoque, nitidez e detecção de bordas utilizando kernels de convolução.

## Funcionalidades Implementadas
- **Inversão de Cores**: Gera uma imagem negativa invertendo os valores de pixel.
- **Desfoque (Blur)**: Aplica um filtro de desfoque utilizando um kernel de média (box blur).
- **Nitidez (Sharpen)**: Realça os contornos e detalhes da imagem utilizando um kernel de nitidez.
- **Detecção de Bordas (Sobel)**: Usa operadores de Sobel para identificar as bordas horizontais e verticais.
- **Correlações com Kernel**: Permite aplicar filtros personalizados através de convolução.
